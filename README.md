### Step 1: Preparation

Makesure Node.js already installed (minimum version 18 or newest LTS preffered).

Check this command:
```
  node -v
```
```
  npm -v
```

Create new project folder:
```
  mkdir chat-websocket
```
```
  cd chat-websocket
```
Initiate Node.js project:
```
  npm init -y
```
### Step 2: Install Dependencies
Run this command inside your project folder:
```
  npm install express socket.io axios cors
```
### Step 3: Create *server.js* and *index.html* Files

### Step 4: Run Server
```
  node server.js
```
Note: *for restart automatically when codes change/update (recommended for development):*
```
  npm install -g nodemon
```
```
  nodemon server.js
```
